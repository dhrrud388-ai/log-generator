# 게임 로그 말풍선 생성기 (티스토리용)

비주얼 노벨 스타일의 게임 스토리 로그를 편집하고, 티스토리 HTML 모드에 그대로 붙여넣을 코드를 만들어 주는 웹 앱입니다.
서버·DB·빌드 과정 없이 브라우저에서만 동작합니다.

## 파일 구성
- `index.html` : 화면 구조
- `style.css`  : 편집기 UI 스타일 (생성되는 로그 디자인과는 별개)
- `script.js`  : 모든 기능 (생성되는 로그의 CSS도 여기서 `.vnlog` 범위로 만들어집니다)

## 실행 방법
1. **바로 열기**: 세 파일을 같은 폴더에 두고 `index.html`을 브라우저로 엽니다.
2. **GitHub Pages**
   1. 새 저장소를 만들고 세 파일을 저장소 맨 위(루트)에 업로드합니다.
   2. Settings → Pages → Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
   3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 사용할 수 있습니다.

## 티스토리에 올리는 방법
1. 오른쪽 **코드** 탭 → **전체 코드 복사**
2. 티스토리 글쓰기 → 상단 **기본모드 ▾ → HTML** 로 전환
3. 붙여넣고 저장

## 사용 팁
- 이미지는 **URL 방식**을 권장합니다. 로컬 파일을 올리면 Data URL로 코드에 들어가 용량이 커집니다.
- 작업 내용은 브라우저에 자동 저장됩니다(최근 작업 12개). 다른 기기로 옮기려면 **로그 저장**(JSON)을 사용하세요.
- 캐릭터 목록은 브라우저(localStorage)에 저장되며 **새로 만들기**를 해도 유지됩니다. 브라우저 데이터를 지우면 사라지니, 로그 JSON 파일에도 캐릭터가 함께 저장됩니다.
- 단축키: `Ctrl+Z` 실행 취소 / `Ctrl+Shift+Z` 다시 실행 / `Ctrl+S` JSON 저장 / 텍스트 선택 후 `Ctrl+B·I·U`
